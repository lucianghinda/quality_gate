## Audit and release contract

The generic `gem-release-ready` audit passes gemspec metadata, current version,
generator/preparer presence, ignored build outputs and the changelog. It reports:

```text
[MISS] .yardopts            not present
[MISS] Gemfile doc gems     missing yard, yard-markdown
[MISS] Rakefile             missing YARD::Rake::YardocTask, docs task
[MISS] gemspec files        does not ship doc/**/*.md, llms.txt
[WARN] git tags             not a git repository
```

The tag warning is a worktree `.git` file detection limitation; Git itself confirms
v0.1.0, v0.2.0, v0.2.2 and v0.2.3, with no v0.3.0 tag. Historical missing tags
are outside this preparation. The four omissions reflect the template's YARD
workflow, rather than this project's tested release contract. `docs/releasing.md`
documents the standard-library `llm.txt` generator; the gemspec explicitly packages
public Markdown and excludes generated YARD output and internal plans. Keep that
contract and existing scripts. Verify actual behavior rather than the generic
audit's substring-based PASS labels.
